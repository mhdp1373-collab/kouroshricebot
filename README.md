# ربات مدیریت مستندات بارنامه (پی‌بار) — نسخه بله

## فایل‌ها
- `bot.py` — کد اصلی ربات
- `requirements.txt` — پکیج‌های پایتون مورد نیاز
- `Procfile` — دستور اجرا برای Railway/Heroku
- `.env.example` — نمونه‌ی متغیرهای محیطی مورد نیاز
- `.gitignore` — جلوگیری از آپلود فایل‌های حساس/موقت

## راه‌اندازی روی Railway

1. این ریپو رو به گیت‌هاب پوش کن (دقیقاً همین فایل‌ها، به‌جز `.env`).
2. در Railway یک پروژه‌ی جدید از روی این ریپو بساز.
3. در تب **Variables** سرویس، متغیرهای زیر رو تعریف کن (مقادیر واقعی خودت رو بذار):
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `STORAGE_CHANNEL_ID` (اختیاری — می‌تونه خالی بمونه)
4. اگه Railway باز هم دستور اجرا رو پیدا نکرد، در **Settings → Deploy → Custom Start Command** بنویس:
   ```
   python bot.py
   ```
5. اگه سرویس بعد از دیپلوی مدام ری‌استارت می‌شه، **Healthcheck** رو در تنظیمات سرویس غیرفعال کن — چون این ربات با polling کار می‌کنه و پورتی برای healthcheck باز نمی‌کنه.

## اجرای محلی (تست روی سیستم خودت)

```bash
pip install -r requirements.txt
cp .env.example .env   # بعد مقادیر واقعی رو داخلش بنویس
python bot.py
```

## نکات مهم
- توکن رو حتماً از `@Bot_Father` **داخل خودِ بله** بگیر، نه تلگرام.
- فایل `.env` هرگز نباید به گیت‌هاب آپلود بشه.
- فایل `database.json` بعد از اولین اجرا خودکار ساخته می‌شه؛ روی Railway این فایل با هر ری‌دیپلوی از بین می‌ره (فضای ذخیره‌سازی موقتیه)، پس برای نگه‌داری دائمی داده‌ها بهتره بعداً به یک دیتابیس واقعی (مثل PostgreSQL که خودِ Railway هم ارائه می‌ده) مهاجرت کنی.
