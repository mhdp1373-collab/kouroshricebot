# 🚛 ربات مستندات پی‌بار — راهنمای نصب

ربات مدیریت آپلود مستندات بارنامه برای پیام‌رسان **بله**

---

## 📋 پیش‌نیازها

- اکانت [GitHub](https://github.com)
- اکانت [Railway](https://railway.app)
- توکن ربات بله (از BotFather بله)
- آیدی عددی تلگرامی خودتان (برای ادمین)

---

## 🔑 مرحله ۱ — دریافت توکن ربات بله

1. در بله سرچ کنید: `BotFather`
2. دستور `/newbot` بزنید
3. اسم ربات بدید
4. یوزرنیم ربات بدید (باید به `bot` ختم بشه)
5. توکن دریافتی را کپی کنید

---

## 🔢 مرحله ۲ — پیدا کردن آیدی عددی ادمین

1. در بله با `@userinfobot` چت کنید
2. دستور `/start` بزنید
3. عدد `Id` که نمایش داده می‌شه = آیدی شماست

---

## 🐙 مرحله ۳ — آپلود به GitHub

1. وارد [github.com](https://github.com) بشید
2. دکمه **New repository** بزنید
3. اسم مثلاً `paybار-bot` بدید
4. **Private** انتخاب کنید (مهم!)
5. **Create repository** بزنید
6. فایل‌های پروژه را آپلود کنید:
   - `bot.py`
   - `requirements.txt`
   - `Procfile`
   - `runtime.txt`
   - `.gitignore`
   - `README.md`

> ⚠️ هرگز فایل `.env` یا `database.json` را آپلود نکنید!

---

## 🚂 مرحله ۴ — دیپلوی روی Railway

1. وارد [railway.app](https://railway.app) بشید
2. **New Project** → **Deploy from GitHub repo**
3. ریپازیتوری خودتون رو انتخاب کنید
4. بعد از ساخت پروژه، روی سرویس کلیک کنید
5. تب **Variables** را باز کنید
6. متغیرها را اضافه کنید:

| نام متغیر | مقدار |
|-----------|-------|
| `BOT_TOKEN` | توکن ربات بله |
| `ADMIN_IDS` | آیدی عددی ادمین |
| `STORAGE_CHANNEL_ID` | آیدی کانال (اختیاری) |

7. تب **Settings** → بخش **Deploy** → مطمئن شید **Root Directory** خالی باشه
8. Railway به‌صورت خودکار دیپلوی می‌کند

---

## ✅ مرحله ۵ — تست ربات

1. در بله ربات خودتون رو سرچ کنید
2. `/start` بزنید
3. اگر منو نمایش داده شد = ربات آنلاین است ✅

---

## 🔧 عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| ربات جواب نمی‌دهد | توکن را در Railway چک کنید |
| خطای `ADMIN_IDS` | مطمئن شید آیدی عددی است نه یوزرنیم |
| ربات restart می‌شود | لاگ Railway را چک کنید |

برای دیدن لاگ: Railway → پروژه → تب **Logs**

---

## 📁 ساختار فایل‌ها

```
├── bot.py              # کد اصلی ربات
├── requirements.txt    # کتابخانه‌های پایتون
├── Procfile            # دستور اجرا برای Railway
├── runtime.txt         # نسخه پایتون
├── .gitignore          # فایل‌های نادیده‌گرفتنی
└── README.md           # این فایل
```
